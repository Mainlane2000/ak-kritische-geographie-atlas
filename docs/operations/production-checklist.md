# Produktionscheckliste

- [ ] Secrets pro Umgebung neu generieren; keine Beispielwerte nutzen.
- [ ] Managed PostgreSQL mit PostGIS-Unterstützung verifizieren.
- [ ] Directus-Rollen/Policies und published-only-Filter testen.
- [ ] BBox, Payload-Größe, Filter und Rate-Limits serverseitig validieren.
- [ ] Keine Admin-Tokens/DB-Zugangsdaten im Client-Bundle.
- [ ] HTTPS, sichere Cookies, CORS/CSRF-Konzept und Security Headers.
- [ ] Backups automatisieren und Restore praktisch testen.
- [ ] Logging, Monitoring, Alerting und Fehlertracking aktivieren.
- [ ] DSGVO: Rechtsgrundlage, Datenschutzhinweise, Löschkonzept, AV-Verträge.
- [ ] WCAG 2.2 AA: Tastaturbedienbarkeit und textuelle Kartenalternative.
- [ ] Tile-/Geocoding-Lizenzen, Attribution und Datenschutz prüfen.
- [ ] Datenquelle, Lizenz, Datum, Transformation und Unsicherheit importierter Daten dokumentieren.
