# Architecture Decision Records

1. Next.js + TypeScript als Web-/API-Basis.
2. Directus als redaktionelles CMS.
3. PostgreSQL + PostGIS als Datenbank.
4. MapLibre GL JS als Kartenbibliothek.
5. GeoJSON im MVP, MVT bei wachsender Datenmenge.
6. `/api/v1` als stabile Abstraktionsschicht.
7. Managed Hosting in EU-Region.
8. Geometrien getrennt von redaktionellen Einträgen modellieren.
9. Rollen- und Freigabeworkflow.
10. pnpm-Monorepo mit gemeinsamen Verträgen.

Jede ADR sollte Status, Kontext, Entscheidung, Alternativen, Konsequenzen und Datum enthalten.
